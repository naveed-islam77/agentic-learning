# LLM Orchestration

## Main task

Sales Manager teen writers se alag styles mein sales email drafts likhwata hai, ek behtareen draft chunta hai, aur use email tool se bhejta hai.

## Kaam ka flow

1. Professional, humorous, aur executive style ke writer agents bante hain.
2. Manager har writer se email draft leta hai.
3. Manager drafts mein se ek chunta hai.
4. Email tool selected draft bhejta hai.

Is example mein agent doosre agents ko tools ke zariye kaam deta aur unka output use karta hai.
